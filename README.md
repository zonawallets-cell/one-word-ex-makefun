One word from your ex: **placeholder**.

`main.py` (pure Python standard library, `os` only) writes exactly one word
— 11 characters — the word an ex would use to describe you, to
`/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Writes the word to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the
output directory). Deterministic: the same word, byte for byte, on every run.
